## Machine Learning Classification Project (ITAI 1371)

### Credit Risk Classification System
GitHub Repository:  
[Final Exam Credit Risk Classification Project](https://github.com/Mixhael134/FinalExam_MichaelRodriguez_ITAI1371)

### Project Overview
This machine learning project focused on predicting whether a borrower would default on a loan using financial and demographic information. Multiple classification models were trained and compared to determine which model performed best for credit risk prediction.

### Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- K-Nearest Neighbors (KNN)
- Support Vector Classifier (SVC)
- Gaussian Naive Bayes
- Voting Ensemble Model

### Key Results
- Random Forest achieved the strongest overall performance
- Ensemble learning improved prediction stability
- Achieved approximately 93% accuracy on test data
- ROC-AUC score exceeded 0.93
